# FractalGo

Software independiente bilingüe, con interfaz visual, cuadernos autónomos y reproducción de los diagnósticos GP/Cassini.

Citar la versión utilizada: Facundo Firmenich. FractalGo, v0.1.0. [doi:10.5281/zenodo.24383318](https://doi.org/10.5281/zenodo.24383318).
